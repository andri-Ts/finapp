# FinApp Backend

API backend de l'application **FinApp**, une application de gestion de budget personnel permettant aux utilisateurs de gérer leurs comptes, catégories et transactions.

## 🚀 Objectifs du projet

FinApp permet de :

- suivre ses revenus et dépenses ;
- gérer plusieurs comptes ;
- organiser les transactions par catégories ;
- mettre à jour automatiquement les soldes des comptes ;
- préparer une base solide pour une application frontend moderne.

---

# 🛠️ Stack technique

## Backend

- Node.js
- Express.js
- TypeScript

## Base de données

- PostgreSQL
- Prisma ORM
- Docker

## Sécurité et validation

- JWT pour l'authentification
- Zod pour la validation des données
- bcrypt pour le hash des mots de passe
